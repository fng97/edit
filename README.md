A simple text editor.
[No dependencies](https://tigerstyle.dev/#zero-dependencies) aside from the
[Zig](https://ziglang.org) toolchain and [Ghostty](https://ghostty.org/).
[Static memory allocation](https://tigerstyle.dev/#static-memory-allocation).

Leaning on these:

- [Kitty Keyboard Protocol](https://sw.kovidgoyal.net/kitty/keyboard-protocol/)
- [In-Band Resize Notifications](https://gist.github.com/rockorager/e695fb2924d36b2bcf1fff4a3704bd83)
